# 快捷录屏 · Quick Region Recorder

在访达或 Chrome 网页的空白处右键，选择 **区域录屏**。拖动框选，确认后开始录制。录制时屏幕上会显示红点、计时和停止按钮，悬浮条不出现在保存的视频里。

## 安装

需要 macOS 15 或更新版本，以及带 Swift 6 的 Xcode 命令行工具。在终端运行 `xcode-select --install` 可以安装命令行工具。

下载本仓库源码，在终端进入解压后的目录，再运行：

```bash
./install.sh
```

脚本会用当前 Mac 的架构构建应用，将它安装到 `~/Applications` 并注册访达扩展。若 `/Applications` 已有同一个应用，脚本会在原位置更新。源码版在本机编译和签名。

### Chrome 网页右键入口

安装应用后，在项目目录运行 `./install-chrome.sh`，然后在 Chrome 打开 `chrome://extensions/`。开启 **开发者模式**，点 **加载未打包的扩展程序**，选择脚本最后打印的目录。安装应用时也可以用 `./install.sh --chrome` 同时准备 Chrome 扩展。

扩展只在右键菜单被选中时向本机应用发送打开框选的指令。它不需要读取网页内容的权限。

## 使用

1. 在访达窗口或 Chrome 网页的空白处右键，选 **区域录屏**。
2. 第一次使用时，在 macOS 的 **隐私与安全性 → 录屏与系统录音** 中允许 **快捷录屏**。按系统提示重新打开应用，再从右键菜单进入。
3. 拖动框选一块区域，点击 **开始录屏**。按 `Esc` 可取消框选。
4. 点击悬浮条上的 **停止**。MP4 会保存到 `~/Movies/快捷录屏`，内容包括画面和鼠标光标。

如果访达菜单没有出现，到 **系统设置 → 通用 → 登录项与扩展** 确认快捷录屏的访达扩展已启用。

## 更新后重新授权

源码版重新构建后，macOS 可能仍显示旧构建的录屏授权。如果开关显示已开启但应用仍要求授权，先退出快捷录屏，再在终端只重置这一个应用的录屏权限：

```bash
tccutil reset ScreenCapture com.kongdexi.quick-region-recorder
```

回到 **录屏与系统录音**，用添加按钮选择已安装的 **快捷录屏.app** 并开启权限，然后再次打开右键菜单。录制文件保存在用户本地，不需要账号或网络连接。

## 开发

`./build.sh` 只在当前项目目录生成应用包。应用用 Swift、AppKit 和 ScreenCaptureKit 构建，访达入口使用 Finder Sync，Chrome 入口使用 Native Messaging。
